Personal Prompt Framework

A working set of reusable prompt patterns for scripts, captions, and documentation — a personal system that speeds up my own drafting, not a packaged tool sold or handed to a team.Set corak prompt yang boleh diguna semula untuk skrip, caption, dan dokumentasi — sistem peribadi yang mempercepatkan draf sendiri, bukan alat berpakej yang dijual atau diserahkan kepada pasukan.

BackgroundLatar Belakang

This wasn't planned as a formal system from day one. It grew out of noticing the same corrections kept happening across scripts, captions, and report chapters, and turning those corrections into upfront constraints instead.Ini bukan dirancang sebagai sistem formal sejak awal. Ia terhasil daripada perhatian bahawa pembetulan yang sama sentiasa berlaku merentasi skrip, caption, dan bab laporan, lalu menukar pembetulan tersebut menjadi batasan awal sebaliknya.

PatternCorak

Topic → research → prompt design → AI draft → refinement → doctor-friendly version. The same shape, whether the output is a TikTok script or a report chapter.Topik → penyelidikan → reka bentuk prompt → draf AI → penambahbaikan → versi mesra doktor. Bentuk yang sama, sama ada output itu skrip TikTok atau bab laporan.

CoversMerangkumi

TikTok scripts, Instagram captions, report chapters, and logbook entries — real before/after examples are in the Prompt Engineering Gallery on the main portfolio page.Skrip TikTok, caption Instagram, bab laporan, dan entri logbook — contoh sebelum/selepas sebenar terdapat dalam Galeri Prompt Engineering di halaman portfolio utama.

Why It Stays PersonalSebab Ia Kekal Peribadi

It's honestly a working habit more than a product — a set of constraints I've learned to add upfront (tone, audience, format, length) rather than a tool with a name and a version number.Ia sejujurnya lebih kepada tabiat kerja berbanding produk — satu set batasan yang saya belajar tambah di awal (nada, khalayak, format, panjang) berbanding alat yang mempunyai nama dan nombor versi.

Reflection & Future ImprovementsRefleksi & Penambahbaikan Masa Depan

A reasonable next step would be writing this down properly as a short style guide, so it could actually be handed to someone else instead of living only in habit.Langkah seterusnya yang munasabah ialah menulisnya dengan kemas sebagai panduan gaya ringkas, supaya ia benar-benar boleh diserahkan kepada orang lain berbanding hanya wujud dalam tabiat.
